# 네온 스웜 · NEON SWARM

레트로 네온 감성의 고정 화면 아케이드 슈팅 게임입니다. 클래식 고정 슈터의 *손맛*(편대 비행, 급강하 공격, 호위 비행)에서 영감을 받았지만, 그래픽·사운드·이름·편대 배치는 모두 이 프로젝트를 위해 새로 만든 것입니다.

- 순수 HTML / CSS / 바닐라 JavaScript — 빌드 과정, 외부 라이브러리, 원격 리소스 없음
- 모든 스프라이트는 코드 속 픽셀 맵으로 절차적으로 그리고, 모든 효과음은 Web Audio로 합성합니다

## 실행 방법

**바로 열기:** `index.html` 파일을 브라우저에서 더블클릭해 열면 됩니다 (`file://`에서도 동작).

**로컬 서버(권장, 모바일 기기 테스트 시):**

```bash
cd /home/chocova/new_project
python3 -m http.server 8000      # 또는: npm start
# 브라우저에서 http://localhost:8000 접속
```

## 조작법

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 좌우 이동 | `←` `→` 또는 `A` `D` | ◀ ▶ 버튼, 또는 화면을 끌기 |
| 발사 (누르고 있으면 연사) | `Space` | 발사 버튼 (화면을 끌면 자동 발사) |
| 시작 / 다시 하기 | `Enter` | 버튼 터치 |
| 일시정지 / 계속 | `P` 또는 `Esc` | 상단 ⏸ 버튼 |
| 소리 켜기/끄기 | `M` | 상단 🔊 버튼 |

키는 물리 키 위치(`event.code`)로 인식하므로 한글 입력 상태에서도 `A`/`D`/`P`/`M`이 동작합니다.

## 게임 규칙

- 적은 화면 밖에서 곡선 경로로 날아와 편대를 이룬 뒤, 하나씩(또는 호위기를 거느리고) 급강하합니다.
- **드론** 50점 · **스팅어** 80점 · **워든** 150점(2발 필요). 급강하 중인 적을 격추하면 점수가 2배 이상입니다.
- 초록 **×2 캡슐**을 먹으면 12초간 트윈 샷. 10,000점, 이후 30,000점마다 보너스 생명.
- 스테이지를 클리어할 때마다 보너스 점수. 편대 모양 4종이 순환하며 급강하 빈도·속도, 동시 급강하 수, 적 탄속·사격 수, 지그재그 기동, 호위 비행 확률이 점점 올라갑니다(9스테이지부터 스팅어 체력 증가).
- 최고 점수와 음소거 설정은 `localStorage`에 저장됩니다(저장소를 쓸 수 없는 환경에서도 게임은 정상 동작).

## 접근성

- 모든 UI 문구는 한국어, 메뉴는 실제 `<button>`이며 키보드만으로 조작할 수 있습니다.
- 화면 전환 시 포커스를 적절한 버튼(시작/계속하기/다시 하기) 또는 게임 캔버스로 옮기고, 눈에 잘 띄는 포커스 표시를 제공합니다.
- 연사 키(Space)를 누른 채 게임 오버가 되어도 '다시 하기'가 실수로 눌리지 않도록, 키를 뗄 때까지 포커스 이동을 지연합니다.
- 스테이지 시작·피격·보너스·게임 오버 등을 `aria-live` 영역으로 스크린 리더에 알립니다.
- 휴대폰 가로 모드에서는 이동 버튼은 왼쪽 아래, 발사 버튼은 오른쪽 아래에 두어 게임 화면이 전체 높이를 사용합니다. 작은 화면에서는 HUD 글자를 자동으로 키웁니다.
- `prefers-reduced-motion` 설정 시 화면 흔들림·워프 효과·CSS 애니메이션을 줄입니다.
- 창이 포커스를 잃거나 탭이 숨겨지면 자동으로 일시정지됩니다.

## 파일 구조

```
index.html            페이지 구조, 메뉴 오버레이, 터치 버튼
css/style.css         레트로 네온 스타일, 반응형 레이아웃, CRT 스캔라인
js/logic.js           순수 로직: 난이도, 편대, 비행 경로(베지어), 충돌, 점수, 최고 점수 저장
js/sprites.js         픽셀 맵 스프라이트와 네온 글로우 사전 렌더링
js/audio.js           Web Audio 합성 효과음, 음소거
js/game.js            게임 엔진: 상태 머신, 갱신, 충돌 처리, 캔버스 렌더링 (DOM 비의존)
js/main.js            브라우저 연결: 크기 조정, 키보드/터치 입력, 포커스 관리, 게임 루프
tests/logic.test.js   로직·데이터 단위 테스트
tests/game.test.js    엔진 헤드리스 시뮬레이션 테스트 (가짜 캔버스, 여러 시드 장시간 자동 플레이)
tests/e2e-chrome.mjs  실제 헤드리스 Chrome으로 데스크톱/모바일 E2E 검증 (선택)
```

## 테스트

Node.js 18 이상이 필요합니다(E2E는 Node 22 이상). 설치할 의존성은 없습니다.

```bash
npm test            # = node --test : 단위 + 엔진 시뮬레이션 테스트
npm run check       # 모든 JS 파일 구문 검사
npm run test:e2e    # 헤드리스 Chrome E2E (Chrome이 없으면 자동으로 건너뜀)
```

E2E 테스트는 Chrome/Chromium을 자동으로 찾습니다(`CHROME_PATH`로 지정 가능). 시작/이동/연사/일시정지/음소거/게임 오버/최고 점수 저장/포커스 이동/멀티 터치를 확인하고, 데스크톱·휴대폰 세로·가로(844×390, 667×375) 화면마다 메뉴 잘림, 버튼과 게임 화면의 겹침, 화면 밖 배치를 자동으로 검사하며, 콘솔 오류가 없는지 검사하며, 스크린샷을 임시 폴더(또는 `SCREENSHOT_DIR`)에 저장합니다.
